Course Outline Module — AI Use Section

AI Use Course Outline Builder

Switch courses above, then fill in one assignment at a time. Each save adds it to that course's outline, and everything is kept between visits.

Purpose

Ambiguity about AI is the thing most likely to produce unfair outcomes and bad-faith arguments — some students guess conservatively and lose out, others exploit the gray area. This form exists to close that gap before an assignment goes out, by forcing a clear, written answer to three questions for every assignment: is AI allowed, required, or restricted here; why; and how will students actually be told.

Each saved assignment becomes part of a standing record for the course — reusable term to term, consistent across sections, and easy to hand to a co-instructor, a TA, or a program reviewer.

Saving & sharing — how this actually works

  • This tool works best opened in Claude (claude.ai or the Claude app) — that's what powers the autosave below. Keep working from there if you want your outline to just be there every time you come back, with nothing to remember to do.
  • Autosave keeps every course and assignment while you're working in Claude — close it and reopen it later, and everything is still there, with no export/import step required.
  • Opened elsewhere — a plain browser tab, GitHub Pages, or anywhere outside Claude — autosave won't carry data between sessions — a banner on the left will tell you if that's happening. In that case, click Export JSON before you close the tab, and Import JSON when you come back.
  • To share your work or back it up, click Export JSON — it saves every course and assignment into one file you can email, store, or hand to a co-instructor. Send that file along with this tool if the other person needs to open it.
  • Importing a JSON file replaces everything currently here — export your current work first if you're not sure you want to lose it.
